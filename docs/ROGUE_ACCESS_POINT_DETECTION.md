# Rogue Access Point Detection Boundary

NetGuard provides conservative wireless indicators, not confirmed rogue access
point detection. A new BSSID for a known SSID, an open network, or a security
downgrade is recorded with its source and limitations and remains
`INFORMATIONAL`.

The same SSID can legitimately use multiple BSSIDs for mesh, roaming, guest
networks, or replacement hardware. Client-mode Windows WLAN output cannot
establish ownership, physical location, packet interception, or whether an
access point is authorized.

Investigate indicators using authorized wireless controller records, switch
port information, site surveys, and administrative change records. Do not
block or disconnect a device based solely on these observations.
