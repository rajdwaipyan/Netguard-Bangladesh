# Code of Conduct

## Our standard

Participation in the NetGuard Bangladesh project requires respectful,
constructive, and professional behavior. Contributors should welcome differing
technical perspectives, focus on evidence, and help maintain a safe community.

## Expected behavior

- Communicate respectfully and assume good faith.
- Provide actionable technical feedback.
- Protect private information and security-sensitive data.
- Accept correction when evidence changes a conclusion.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, publication of
private data, and malicious use of project tooling are not acceptable.

## Enforcement

Report conduct concerns privately to the project maintainers through the
repository's configured private contact channel. If no channel is configured,
request one without publishing sensitive details.
